# Edge TTS benchmark workspace

Generated by `tools/bench/`. Isolated from the pilot: nothing here touches
`data/audio-master/`, `data/audio-final/`, the app database, ingestion
checkpoints, or semantic card data.

- `wordsets/` — word lists, including the deterministic Oxford samples.
- `voices/round1`, `voices/round2` — voice screening and the deeper voice test.
- `formats/round3` — Edge source-format acceptance probe and format comparison.
- `interaction/round4` — top voices x best formats cross-check.
- `holdout/round5` — unseen validation.
- `analysis/` — spectrogram contact sheets and ad-hoc comparisons.
- `report.md` — the findings.

Each round directory holds `master/` (bytes Edge returned), `final/` (the same
clips through the production FFmpeg chain to Ogg Opus 64 kbps mono),
`index.jsonl` (what was requested) and `metrics.jsonl` (what was measured).
Audio is gitignored; the JSONL evidence and the report are not.

## Release packaging note

The production TTS profile these rounds selected is frozen into the shipped
importer sidecar (`tools/build_importer_sidecar.ps1`). The installed app carries
its own FFmpeg, so the encoder half of the fingerprint is fixed at install time
too; see the "How the importer ships" section of the top-level README.
